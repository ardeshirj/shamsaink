# en-basics

A day in the city, in English: a title page and three short chapters (morning, the market, the park), and a contents.
`dc:language en`, no direction stated (left to right, the default). The same day as the right-to-left books, so their
pages can be compared.

Tests (`e2e/scenarios/walk-en.txt`): the walk of every screen on a left-to-right book, the interface in English, from its
fixture (`e2e/fixtures/en-basics`). It replaced IDPF's Moby-Dick sample (2026-11-13), so CI downloads nothing.

The text is ours, written for these tests (Apache-2.0, as the repository).
